# Skill Methodology Project

This project contains the Anthropic Skill building methodology and the Skill Forge tool.

## Available Skills

### Skill Forge (`/skill-forge`)

When the user wants to create, build, or design a new Anthropic Skill, activate the Skill Forge.

**How to activate:** The user says anything about creating/building/designing a skill, or types `/skill-forge`.

**Instructions location:** Read and follow the complete instructions in `skills/skill-forge/SKILL.md`.

**Reference materials** (load only when needed during specific phases):
- `skills/skill-forge/references/anti-patterns.md` — During Phase 1 (kill criteria) and Phase 5 (hardening)
- `skills/skill-forge/references/attention-curve.md` — During Phase 3 (instruction architecture)
- `skills/skill-forge/references/description-patterns.md` — During Phase 2 (description engineering)
- `skills/skill-forge/references/five-patterns.md` — During Phase 3 (instruction architecture)
- `skills/skill-forge/references/scorecard.md` — During Phase 5 (hardening)

**Important:** Follow the forge sequence strictly. Never skip phases. Never generate a SKILL.md in one shot.
